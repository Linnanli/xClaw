# 环境不一致问题分析

## 当前项目的环境不一致问题分类

### 1. 浏览器端（前端）- 已识别 ✓

#### 问题
- EventSource API 不支持自定义 HTTP 头
- 需要通过 URL 参数传递认证令牌
- 浏览器发送 CORS 预检请求（OPTIONS）
- 浏览器自动处理重连

#### 影响
- SSE 连接需要特殊处理
- 认证方式与后端集成测试不同
- CORS 配置必须包含 OPTIONS 方法

#### 解决方案
- ✅ 已实现：使用 EventSource API + URL 参数认证
- ✅ 已实现：CORS 配置包含 OPTIONS 方法

---

### 2. Tauri 应用端（桌面应用）- 需要关注 ⚠️

#### 问题
- Tauri 使用 WebView（基于系统浏览器引擎）
- 不同操作系统的 WebView 实现不同
- Tauri 命令和浏览器 API 的混合使用
- 本地文件系统访问权限差异

#### 具体差异

**macOS vs Windows vs Linux**
```
macOS:
- WebKit 引擎
- 文件系统：/Users/username/...
- 权限模型：基于用户

Windows:
- Edge WebView2 引擎
- 文件系统：C:\Users\username\...
- 权限模型：基于用户和管理员

Linux:
- GTK WebKit 引擎
- 文件系统：/home/username/...
- 权限模型：基于用户
```

**Tauri 命令 vs 浏览器 API**
```
Tauri 命令（Rust 后端）：
- 直接访问文件系统
- 直接访问系统资源
- 可以执行系统命令

浏览器 API：
- 受沙箱限制
- 需要用户权限
- 受 CORS 限制
```

#### 影响
- 跨平台兼容性问题
- 文件路径处理差异
- 权限管理差异
- API 调用方式差异

#### 当前项目中的具体问题

1. **API 调用方式混合**
   ```typescript
   // 浏览器 API（受 CORS 限制）
   const response = await fetch('http://localhost:3000/api/chat/threads');
   
   // Tauri 命令（直接调用 Rust 后端）
   const threads = await invoke('get_threads');
   ```

2. **文件路径处理**
   ```rust
   // macOS
   let path = "/Users/nallylin/.ironclaw/ironclaw.db";
   
   // Windows
   let path = "C:\\Users\\nallylin\\.ironclaw\\ironclaw.db";
   
   // Linux
   let path = "/home/nallylin/.ironclaw/ironclaw.db";
   ```

3. **权限管理**
   - 本地数据库访问
   - 文件系统访问
   - 网络访问

### 3. 后端服务端（Rust 后端）- 需要关注 ⚠️

#### 问题
- 本地开发 vs 生产环境配置差异
- 数据库连接方式差异
- 认证令牌生成和管理
- 日志级别和输出方式

#### 具体差异

**开发环境**
```rust
// 本地 SQLite 数据库
DATABASE_BACKEND=libsql
LIBSQL_PATH=/Users/nallylin/.ironclaw/ironclaw.db

// 调试日志
LOG_LEVEL=debug

// 本地 API
API_BASE_URL=http://localhost:3000

// 认证令牌自动生成
GATEWAY_AUTH_TOKEN=<auto-generated>
```

**生产环境**
```rust
// 远程数据库
DATABASE_BACKEND=postgres
DATABASE_URL=postgresql://user:pass@host:5432/db

// 生产日志
LOG_LEVEL=warn

// 生产 API
API_BASE_URL=https://api.example.com

// 认证令牌从环境变量读取
GATEWAY_AUTH_TOKEN=<from-env>
```

#### 影响
- 数据库连接失败
- 日志输出不一致
- 认证令牌管理混乱
- 性能差异

#### 当前项目中的具体问题

1. **数据库配置**
   ```rust
   // 开发环境：本地 SQLite
   let db = libsql::Builder::new_local(path).build().await?;
   
   // 生产环境：应该使用 PostgreSQL
   // 但当前代码可能不支持
   ```

2. **认证令牌管理**
   ```rust
   // 每次启动生成新令牌
   let token = generate_random_token();
   
   // 问题：前端需要知道新令牌
   // 解决方案：应该从配置文件或环境变量读取
   ```

3. **日志输出**
   ```rust
   // 开发环境：详细日志
   tracing::debug!("SSE connection from {:?}", remote_addr);
   
   // 生产环境：应该只输出重要日志
   ```

### 4. 网络环境 - 需要关注 ⚠️

#### 问题
- 本地网络 vs 互联网
- 防火墙和代理
- DNS 解析
- 网络延迟和超时

#### 具体差异

**本地开发**
```

```

```

```

#### 影响
- 超时设置不适用
- 重试逻辑不适用
- 连接池配置不适用

#### 当前项目中的具体问题

1. **超时设置**
   ```typescript
   // 开发环境：30 秒超时
   const timeout = 30000;
   
   // 生产环境：应该是 10 秒
   const timeout = 10000;
   ```

2. **重试逻辑**
   ```typescript
   // 开发环境：重试 3 次
   const maxRetries = 3;
   
   // 生产环境：应该是 5 次
   const maxRetries = 5;
   ```

### 6. 操作系统 - 需要关注 ⚠️

#### 问题
- 文件系统差异（大小写敏感性）
- 路径分隔符差异
- 权限模型差异
- 系统调用差异

#### 具体差异

**macOS**
```
文件系统：不区分大小写（通常）
路径分隔符：/
权限：基于用户
系统调用：POSIX
```

**Windows**
```
文件系统：不区分大小写
路径分隔符：\ 或 /
权限：基于用户和管理员
系统调用：Win32
```

**Linux**
```
文件系统：区分大小写
路径分隔符：/
权限：基于用户和组
系统调用：POSIX
```

#### 影响
- 文件找不到
- 路径处理错误
- 权限拒绝
- 系统调用失败

#### 当前项目中的具体问题

1. **文件路径**
   ```rust
   // 错误：硬编码 macOS 路径
   let path = "/Users/nallylin/.ironclaw/ironclaw.db";
   
   // 正确：使用 dirs crate
   let path = dirs::data_dir()
       .unwrap_or_else(|| PathBuf::from("."))
       .join("ironclaw")
       .join("ironclaw.db");
   ```

2. **路径分隔符**
   ```rust
   // 错误：硬编码 /
   let path = "config/settings.json";
   
   // 正确：使用 Path
   let path = Path::new("config").join("settings.json");
   ```

## 建议的解决方案

### 1. 创建环境配置管理系统
```rust
// config/development.toml
[api]
base_url = "http://localhost:3000"
timeout = 30
retry = 3

[database]
backend = "libsql"
path = "~/.ironclaw/ironclaw.db"

[auth]
method = "both"  # header + url_parameter

// config/production.toml
[api]
base_url = "https://api.example.com"
timeout = 10
retry = 5

[database]
backend = "postgres"
url = "postgresql://..."

[auth]
method = "header"
```

### 2. 创建跨平台路径管理
```rust
pub fn get_data_dir() -> PathBuf {
    dirs::data_dir()
        .unwrap_or_else(|| PathBuf::from("."))
        .join("ironclaw")
}

pub fn get_config_path() -> PathBuf {
    get_data_dir().join("config.toml")
}

pub fn get_db_path() -> PathBuf {
    get_data_dir().join("ironclaw.db")
}
```

### 3. 创建认证令牌管理
```rust
pub struct AuthTokenManager {
    token_file: PathBuf,
}

impl AuthTokenManager {
    pub fn load_or_generate() -> Result<String> {
        let path = get_data_dir().join(".auth_token");
        
        if path.exists() {
            std::fs::read_to_string(&path)
        } else {
            let token = generate_random_token();
            std::fs::write(&path, &token)?;
            Ok(token)
        }
    }
}
```

### 4. 创建网络配置管理
```rust
pub struct NetworkConfig {
    pub timeout: Duration,
    pub retry_count: u32,
    pub retry_delay: Duration,
}

impl NetworkConfig {
    pub fn development() -> Self {
        Self {
            timeout: Duration::from_secs(30),
            retry_count: 3,
            retry_delay: Duration::from_millis(1000),
        }
    }
    
    pub fn production() -> Self {
        Self {
            timeout: Duration::from_secs(10),
            retry_count: 5,
            retry_delay: Duration::from_millis(2000),
        }
    }
}
```

### 5. 创建依赖版本检查

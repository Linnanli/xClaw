### 2. 后端 API ✅

#### 用户角色管理 API
- **文件**: `admin-backend/src/routes.rs`
- **端点**:
  - `GET /api/users` - 获取用户列表（包含角色信息）
  - `GET /api/users/{id}/roles` - 获取用户的角色列表
  - `POST /api/users/{id}/roles` - 分配用户角色

#### 功能特性
- 用户列表自动加载角色信息
- 分配角色时先删除现有角色，再添加新角色
- 验证角色是否存在
- 验证用户是否存在
- 返回适当的 HTTP 状态码

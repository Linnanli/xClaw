- [ ] 项目根目录已初始化，包含 `.gitignore` 和基础说明文档
- [ ] **管理后台** (`admin-backend/`)：

  - [ ] `npm run tauri dev` 可以成功启动应用

  - [ ] `requirements.txt` 或环境说明文件存在

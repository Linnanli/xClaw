# IronClaw 架构优化与管理后台功能演进计划

根据对 [architecture.md](file:///c:/codes/ironclaw/governance/architecture.md) 安全架构的分析，以下是管理后台侧建议补充的功能清单：

### 0. 仓库架构决策 (Repository Architecture)
- [x] **后端与核心分离**：管理后台采用独立私有仓库开发，确保业务逻辑安全。
- [x] **前端集成计划**：GUI 代码保留在 Fork 中，计划存放在 `gui/` 独立目录。
- [x] **同步策略**：定期从 `upstream/staging` 合并更新，确保底层引擎持续演进。

### 1. 全网状态感知与监控 (Fleet Observability)
- [ ] **全量客户端在线看板**：实时展示全网在线客户端数量、地理位置分布及版本覆盖率。
- [ ] **终端资源监控**：实时采集并预警终端 WASM 沙箱的 CPU、内存占用及网络流量异常。
- [ ] **行为热力图**：统计高频使用的 Skills 及其成功率，辅助业务决策。

### 2. 资源配额与成本管控 (Quota & Billing)
- [ ] **Token 配额管理**：支持按部门或个人维度设置每日/每月 LLM Token 消耗上限。
- [ ] **算力限制策略**：在后台统一配置 WASM 沙箱的计算优先级和最大运行时间限制。
- [ ] **费用对账中心**：自动汇总公有云/私有化模型的调用成本，生成分摊报表。

### 3. 远程响应与“一键熔断” (Remote Kill-Switch)
- [ ] **Skill 吊销列表 (CRL)**：发现漏洞时，后台一键吊销 Skill 签名，所有终端立即失效。
- [ ] **设备熔断机制**：针对丢失或异常的终端，支持远程强制注销身份令牌并清除本地 SM4 加密库。
- [ ] **应急公告推送**：支持向全网或特定组别的客户端推送强制性的安全通知。

### 4. 模型评估与 LLMOps (Model Eval)
- [ ] **Prompt 管理中心**：集中管理、版本化和分发企业级提示词模板。
- [ ] **多模型对比测试**：支持在后台同时向多个 LLM 发起相同请求，对比回复准确度与延迟。
- [ ] **反馈闭环系统**：收集用户对 AI 回复的点赞/踩，作为模型微调或路由权重调整的依据。

### 5. 客户端自更新管理 (OTA Management)
- [ ] **基座热更新**：支持 Tauri 客户端基座的差分升级，无需用户重新下载安装包。
- [ ] **静默升级策略**：支持针对安全漏洞进行强制性的后台静默升级。
- [ ] **兼容性矩阵管理**：确保不同版本的客户端与不同版本的 Skills 之间的 API 兼容性。

### 6. 执行环境安全增强 (Execution Environment Security)
- [ ] **BoxLite 容器隔离**：深度集成 Linux Namespace 与 Cgroups，为 Python 插件提供零损耗的原生安全隔离环境。
- [ ] **MCP 网桥 (Bridge)**：实现 MCP 协议支持，驱动本地或远程工具。
- [ ] **多运行时切换**：支持在 Docker 与 BoxLite 之间根据宿主机环境自动选择最佳隔离方案。
